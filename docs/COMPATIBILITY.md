# Совместимость API и обновление базы

## API
`python tests/check_contract.py` сравнивает полную OpenAPI-схему с [контрактом](OPENAPI_CONTRACT.json). Любое изменение требует проверки совместимости и версии, затем осознанного обновления снимка. Это проверка схемы; бизнес-поведение отдельно проверяют тесты.

Снимки не перезаписываются в CI. При согласованном изменении запустить проверку с `--record`, изучить diff и зафиксировать новый контракт вместе с изменением API.

## Обновление базы
`python tests/check_upgrade.py` извлекает предыдущий релиз по полному commit SHA из `tests/upgrade-baseline.json`, создаёт отдельную базу старым кодом, затем открывает её текущей версией. Проверяются сохранность записей, `integrity_check` и внешние ключи. Рабочая база не изменяется. Для получения отсутствующего commit нужен доступ к GitHub.

Перед обновлением рабочей установки всё равно создаётся отдельная резервная копия. Проверка выполняется на SQLite; она не подтверждает миграцию данных PostgreSQL или D1.

## GitHub Actions
Внешние Actions закреплены полными commit SHA, комментарии сохраняют имя версии. Dependabot предлагает обновление; перед слиянием выполняется CI.
