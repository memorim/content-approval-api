# Доставка событий

После `alembic upgrade head` запустите `python -m app.outbox` отдельным процессом. В Docker Compose обработчик запускается после готовности приложения. `--once` обрабатывает до 100 доступных событий и завершает процесс; `--status` показывает счётчики; `--retry UUID` возвращает событие из очереди ошибок.

Запись согласования и outbox фиксируются одной транзакцией. Обработчик атомарно арендует событие на 60 секунд; после сбоя процесса аренда освобождается по времени. Максимум пять попыток с увеличивающимся интервалом до 300 секунд, затем событие остаётся в очереди ошибок до явного повторного запуска. В журнал попадают ID, номер попытки и класс ошибки, без содержимого события и токенов.

По умолчанию приёмник сохраняет по одному JSON на ID в `data/delivered-events/`: публикация файла атомарна, повтор сверяет содержимое. Это работающий локальный потребитель событий, внешняя площадка публикации не подключена. Политика хранения файлов определяется владельцем развёртывания.

Владелец может задать фиксированный `OUTBOX_WEBHOOK_URL` (HTTPS) и отдельный `OUTBOX_WEBHOOK_TOKEN`. Пользователи API не управляют адресом назначения. Редиректы не выполняются, TLS проверяется. Внешняя доставка имеет семантику at-least-once: получатель должен дедуплицировать `Idempotency-Key`, равный ID события. Глобальный порядок и exactly-once внешних эффектов не заявляются. В тестах проверяется потеря ответа после применения эффекта, конкурентный захват и повтор после истечения аренды.
